# Credit-Card-Fraud-Detection
## 📊 Dataset
The dataset used in this project is a large-scale **Credit Card Transactions Dataset** consisting of over **1.2 million transactions**. 

* **Size:** ~1,296,675 rows and 24+ initial features.
* **Target Variable:** `is_fraud` (used for stratified sampling and validation).
* **Key Features:** Includes transaction amounts (`amt`), temporal data (`trans_date_trans_time`), and categorical variables like transaction category.

> **Note:** Due to the large file size (approx. 500MB+), the raw CSV file (`credit_card_transactions.csv`) is not included in this repository. You can find similar datasets on [Kaggle](https://www.kaggle.com/datasets?search=credit+card+fraud) by searching for "Credit Card Transactions."
